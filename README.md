# 캠퍼스 스터디 타이머 (Campus Study Timer)

![Project Badge](https://img.shields.io/badge/Project-In_Progress-brightgreen)

## 1. 프로젝트 소개
공부 시간을 측정하고 같은 목표를 가진 학우들과 집중 시간을 비교할 수 있는 간단한 타이머 웹 애플리케이션입니다.

## 2. 만들고 싶은 이유
혼자 공부할 때 집중력이 흐려지는 문제를 해결하고, 가볍게 학우들과 동기부여를 주고받기 위해 시작했습니다.

## 3. 예상 사용자
- 규칙적인 공부 습관을 만들고 싶은 대학생
- 혼자 공부할 때 집중 유지가 어려운 수험생
